# LinChat 黑白 LC 标识

用户确认的方向：**LC 字母与对话融合**，使用纯黑、纯白。

## 图形

左侧是几何 L，右侧是开口 C；C 的下缘延伸成对话气泡尾部。字母不依赖字体，使用独立矢量路径。外框采用圆角方形，适配桌面快捷方式、任务栏、托盘和网页导航。

- 主版：黑色 `#000000` 底、白色 `#ffffff` 图形。
- 反白版：白底黑形，供需要浅色底的品牌物料使用。
- 抗锯齿边缘可能产生灰阶像素；没有彩色、渐变或阴影。
- 不将整个界面主题强制改为黑白，标识在各配色主题中保持一致。

## 资产

| 文件 | 用途 |
|---|---|
| `desktop/assets/logo.svg` | 主标识矢量原稿 |
| `desktop/assets/logo-inverse.svg` | 白底黑形版本 |
| `desktop/assets/icon.png` | 512 × 512 PNG，桌面窗口、通知和连接中心 |
| `desktop/assets/icon.ico` | Windows 应用及安装包，包含 16、24、32、48、64、128、256 像素 |
| `desktop/assets/tray.png` | 32 × 32 托盘图标 |
| `web/public/favicon.svg` | 浏览器标签、登录页和聊天导航标识 |

运行 `npm run icons` 统一生成以上文件；以 `scripts/icons.cjs` 中的几何定义为源，不单独修改生成文件。PNG（含 ICO 内嵌 PNG）附有来源说明。所有图形为本项目原创绘制，没有使用图库或生成图片模型。

客户端安装包需重新构建并安装后，操作系统图标才会更新；网页标识随服务端 Web 资源部署生效。
