## 群聊 @成员

- 群聊和公共大厅输入 `@`，按昵称或账号搜索成员。
- 点击成员，或用 ↑ / ↓ 和 Enter / Tab 选择；支持一条消息提及多人。
- 消息内高亮被提及成员；接收方显示“提到了你”，未读会话显示 `@我`。
- 离线未读提醒会保留，读到消息后清除；最小化时系统通知注明“@了你”。
- 成员按账号 ID 识别，同名昵称、历史改名和消息重发不会串人或重复提醒。

## 桌面版更新提醒

- 正式桌面版启动后自动检查 GitHub 正式发行版，运行期间每 6 小时再检查。
- 新版本显示窗口内提醒和系统通知，点击“下载更新”获取安装包。
- 连接中心、托盘菜单及聊天界面的个人设置中均可手动检查更新。
- 检查失败会显示原因，之后可以重试；不会把旧版本或预览版本当作新版本。

1.0.x 用户先下载安装本次 1.1.0，此后即可收到新版提醒。更新提示提供安装包下载，下载完成后运行安装包升级。

## 下载与使用

**Windows 10/11 x64：下载并双击 `LinChat-Setup-1.1.0.exe`，自动安装并创建桌面快捷方式。**

便携使用选择 `LinChat-Portable-1.1.0.exe`。源码 ZIP 完整解压后，双击 `一键安装使用.cmd` 也可安装。

云端连接地址：https://chat.linblog.site 。新成员通过管理员的邀请链接注册。

@ 功能由所连接的服务端提供：云端需要升级到本版服务端；Radmin 主机升级本版后即可提供该功能。

服务端独立程序也附在本次发行中。已有 SQLite 数据目录会自动增加提及记录表，保留原账号、消息和附件。

已部署为 systemd 服务的云端可使用随附的 `update-cloud.sh`：先验证新二进制，停止服务并备份完整数据目录，再原位更新并检查健康状态；失败时恢复之前的程序。用法见脚本及仓库部署文档。

文件校验值见 `SHA256SUMS.txt`。
