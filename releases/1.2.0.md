# LinChat 1.2.0 · 娱乐模式

现在可以在 LinChat 中与朋友跑一场有角色、掷骰和存档的文字战役。

## 新功能

- **战役空间**：独立文字房间、固定规则版本、当前场景、持久化日志、结束摘要和继续游戏。
- **角色卡**：六项属性、HP、AC、等级、状态、装备、法术与资源，以及单独授权的私密背景。
- **服务器掷骰**：普通、优势／劣势骰式，记录每颗骰子与实际结果；相同请求重试不重复掷骰。
- **三种主持方式**：房主手动主持、Grok／OpenAI 兼容 API 主持、战役专用令牌接入外部智能体。
- **明确触发**：提交行动或在战役群中 @主持人；普通闲聊不消耗模型调用。
- **公开与秘密分离**：玩家、房主和获准智能体按权限读取；内置公开主持不接收主持秘密或私信。
- **可靠推进**：战役行动依次处理，资源与叙述原子提交，暂停和版本检查阻止过期结果覆盖，失败后由房主重试或接手。
- **设定提案**：背景、房规和剧情变更经房主确认后成为正式设定。
- **MCP 与机器人示例**：仓库提供 stdio 连接器和可运行的外部自动主持示例。
- **桌面与手机交互**：切换群聊或战役时保留未发送草稿及私密发送方式；加载失败提供直接重试。

## 开始使用

更新后点击左侧**骰子图标 → 娱乐模式 → 新建战役**。真人手动主持可直接使用；内置 AI 由服务器管理员在“模型设置”填写自己的 API 地址、模型和密钥。

完整文档：[娱乐模式与智能体接入](https://github.com/Lin-6499/ChatForPlay/blob/main/docs/ENTERTAINMENT.md)。

## 安装与升级

- Windows 安装版：`LinChat-Setup-1.2.0.exe`。
- 便携版：`LinChat-Portable-1.2.0.exe`。
- 云端与独立 Radmin 主机都需要更新服务端，连接旧服务端的客户端仍显示旧服务端界面。
- 原有账号、会话、消息与文件保留。升级前备份完整数据目录；1.2.0 后还需保留 `ai-secret.key`。
- 安装包和 Windows/Linux 服务端摘要见 `SHA256SUMS.txt`。

本版兼容原有聊天、文件、@成员和桌面更新提醒。AI 连接与工具调用流程已使用本机模型替身验证；实际付费服务须配置有效密钥、模型权限和额度。
