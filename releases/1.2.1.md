# LinChat 1.2.1 · 自定义安装位置

- Windows 安装包增加安装向导，可点击“浏览”或输入路径，选择其他磁盘、中文或带空格的文件夹。
- 已安装的用户重新运行同版或新版安装包时，可查看原安装位置并选择新位置；安装后自动更新桌面和开始菜单快捷方式。
- 源码包中的 `一键安装使用.cmd` 会下载、校验并打开安装向导；`启动LinChat.cmd` 优先打开已经安装的版本。
- 修正从 Windows 卸载信息识别自定义安装位置的逻辑，支持带版本号的 LinChat 卸载条目。
- 取消安装可正常退出，完成页由用户决定是否立即启动。

下载并运行 **`LinChat-Setup-1.2.1.exe`**，选择目标目录后点击“安装”即可。

程序安装目录与数据目录分开：连接设置、本机聊天及战役数据仍保存在 `%APPDATA%\linchat-desktop`。本版为桌面安装器更新，内置及云端服务端版本为 1.2.0。
